✈️ TravelEra

A full-stack travel booking web application designed to help users explore and book different modes of transportation including **Flights, Trains, Buses, Cars, Ferries, and Rides**.

 🚀 Features

* 🔎 Search and explore travel options
* 🚌 Bus, 🚆 Train, ✈️ Flight, 🚗 Car and 🚢 Ferry listings
* 💺 Seat selection
* 🎫 Booking management
* 👤 User profile system
* ⭐ Reviews and ratings
* 🛠️ Admin management system
* 🔐 Authentication system *(under development)*
* 💳 Payment system *(under development)*

## 🛠️ Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

### Other Technologies

* REST APIs
* JWT Authentication
* Cloudinary
* Payment Gateway integration

## ⚙️ Installation

### Frontend

```bash
cd travelera-frontend
npm install
npm run dev
```

### Backend

```bash
cd travelera-backend/travelera-backend
npm install
npm run dev
```

Create your own environment variables using the provided `.env.example` file.
